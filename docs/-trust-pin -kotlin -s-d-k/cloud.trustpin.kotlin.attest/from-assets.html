fromAssets

@JvmOverloads
fun fromAssets(context: ERROR CLASS: Symbol not found for Context, fileName: String = AttestConstants.DEFAULT_ASSET_FILE): TrustPinAttestConfiguration

Loads the configuration from the JSON asset that also holds the pinning configuration (assets/trustpin.json by default). Java entry point of TrustPinAttestConfiguration.Companion.fromAssets.

KeyRequiredTypeNotes
attest_verifier_urlyesstringHTTPS base URL of your verifier, without the version segment
attested_hostsyesarray of stringHosts that receive the header; *.example.com covers one label; no IP addresses
google_cloud_project_numbernostring or numberYour Google Cloud project number, needed when your policy asks for Play Integrity

Other keys in the file are ignored. TrustPinAttestConfiguration.debugToken is never read from the file.

Throws

TrustPinAttestError.InvalidConfiguration

when the file is missing, a key is missing or a value is invalid; the reason is written to logcat with the [TrustPinAttest] tag.
