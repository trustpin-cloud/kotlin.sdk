TrustPinAttestationProvider

interface TrustPinAttestationProvider

Supplies the attestation headers that TrustPin's OkHttp and Ktor adapters add to outgoing HTTPS requests.

Register one with TrustPin.setAttestationProvider. The TrustPin attestation module registers itself when it is set up; implement this interface only to supply headers from another source.

TrustPin never waits for a provider indefinitely: a provider that does not answer in time, or fails, is ignored for that request and the request is sent without its headers. A provider cannot affect certificate pinning.

The names in headerNames belong to the provider: on every request the adapters send, redirects included, TrustPin removes any header with one of these names and adds the provider's headers for that request's own URL. Headers with other names are left alone, and headers the provider returns without declaring them are never added.
